# Entry template

### <change-id>-<log-code>-<sequence> · <title>

| Field | Record |
| --- | --- |
| Change ID | FH-YYYYMMDD-NNN |
| Entry ID | Shared change ID plus log code and sequence |
| Event date and time zone | Original date, or Unknown. Europe/Dublin unless stated otherwise |
| Recorded date | Date added, including historical backfills |
| Status | Proposed / Approved / Implemented / Verified / Deferred / Superseded |
| Owner and origin | Decision or action owner and source type |
| Before and after | Previous state and actual or intended change |
| Rationale and impact | Why, affected scope, dependencies, trade-offs |
| Evidence | Source ID, exact commit or other private reference, date checked, limitations |
| Verification | Method, expected result, actual result, date and environment |
| Follow-up | Action, owner, target or review date |
| Recovery | Rollback, contingency or Not applicable with reason |
| Related IDs | Supporting, superseded and replacement entries |

Add the category fields listed in the relevant log. Mark unavailable values Unknown. Keep private addresses, credentials, media, exact personal locations and chat transcripts in their authorized private context.
