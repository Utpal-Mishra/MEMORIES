# Project instructions

Maintain the structured audit trail described in [docs/logs/README.md](docs/logs/README.md) alongside major project work.

Before assigning a change ID, review the latest private register and reuse existing IDs for migrated records. Record rationale, affected components, evidence, verification, risk or assumptions, mitigation and follow-up in every applicable category. Preserve previous entries and link corrections.

This repository is public. Keep this directory's records limited to templates and explicitly approved public content. Store detailed project conversation summaries and personal or operational evidence in the owner's private audit register. Check the staged diff for private material before committing.
