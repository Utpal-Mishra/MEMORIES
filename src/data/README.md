# Ireland map geometry

The bundled outline is derived from Natural Earth 1:50m Admin 0 Countries, downloaded on 10 November 2026. It includes the Republic of Ireland and the separate Northern Ireland polygon. Small Irish island polygons are retained.

Source https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_0_countries.geojson

Source SHA-256 `3e458fc036ad0a66411f2c1e6cac49c5d7bfb81cb1123bc513b22511a2b7fdeb`

Natural Earth data is public domain. The outline is a regional overview. Saved coordinates remain exact in the album and can be entered manually.

Coordinates are projected into the 400 × 480 SVG view using `x = (longitude + 11.3) × 64` and `y = (55.8 − latitude) × 100`. The same projection positions the pins and converts map taps into coordinates. No tile or geocoding request is made when opening the map.
